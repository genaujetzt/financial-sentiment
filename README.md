# Финансовые новости — анализ тональности для трейдеров

## Описание проекта

Проект посвящён разработке модели машинного обучения для автоматического определения тональности финансовых новостей.

Модель анализирует текст новости и классифицирует его по одной из трёх категорий:

- **Positive** — позитивная тональность: новости о росте акций, увеличении прибыли, успешных сделках и положительных финансовых результатах.
- **Negative** — негативная тональность: новости об убытках, падении стоимости акций, сокращениях, финансовых проблемах и других негативных событиях.
- **Neutral** — нейтральная тональность: информационные сообщения, не содержащие выраженной положительной или отрицательной оценки.

Основная задача проекта — построить baseline-модель, исследовать способы улучшения её качества и выбрать наиболее эффективный подход.

## Цели проекта

1. Провести исследовательский анализ данных (EDA).
2. Подготовить и очистить текстовые данные.
3. Разработать baseline-модель классификации на основе TF-IDF и Logistic Regression.
4. Экспериментально проверить различные способы улучшения качества классификации.
5. Сравнить модели по метрике Macro F1.
6. Проанализировать ошибки классификации.
7. Реализовать функцию предсказания тональности для новых финансовых новостей.

## Датасет

Для обучения используется размеченный датасет финансовых новостей.

- [Financial PhraseBank (Hugging Face)](https://huggingface.co/datasets/financial_phrasebank)


## Этапы реализации

### 1. Исследовательский анализ данных (EDA)

- Загрузка и первичный анализ датасета.
- Проверка размерности и типов данных.
- Поиск пропущенных значений и дубликатов.
- Анализ распределения классов.
- Исследование длины текстов и количества слов.
- Анализ примеров новостей каждого класса.

**Результат:** графики распределения классов и длины текстов, основные статистические характеристики датасета.

### 2. Предобработка данных

- Приведение текста к нижнему регистру.
- Удаление HTML-тегов.
- Нормализация пробелов.
- Удаление пустых текстов.
- Удаление пустых дубликатов.
- Кодирование целевой переменной.

### 3. Построение baseline-модели

В качестве первого решения используется комбинация:

- **TF-IDF Vectorizer** — преобразование текстов в числовые векторы с учётом важности слов и словосочетаний.
- **Logistic Regression** — классификация финансовых новостей по трём категориям тональности.

Основные параметры TF-IDF:
- `max_features = 5000`
- `ngram_range = (1, 3)`

Данные разделяются на обучающую и тестовую выборки в соотношении 80/20 с сохранением пропорций классов.

### 4. Улучшение модели

Проводятся эксперименты с различными методами повышения качества классификации:

1. **Лемматизация** — приведение слов к начальной форме с использованием spaCy.
2. **Изменение параметров TF-IDF** — использование униграмм, биграмм и триграмм.
3. **Random Forest** — проверка альтернативного алгоритма классификации.
4. **LinearSVC** — использование линейного метода опорных векторов.
5. **Подбор гиперпараметров** — поиск оптимального значения регуляризации для Logistic Regression.

Каждый подход оценивается отдельно, результаты сравниваются с baseline-моделью.

Целевой показатель — улучшение Macro F1 минимум на 5% относительно baseline.

### 5. Сравнение моделей и анализ ошибок

Для оценки качества используются:

- **Accuracy** — доля правильных предсказаний.
- **Precision** — точность предсказаний каждого класса.
- **Recall** — полнота обнаружения объектов каждого класса.
- **F1-score** — гармоническое среднее Precision и Recall.
- **Macro F1** — среднее значение F1-score по всем классам с одинаковым весом каждого класса.

Macro F1 выбрана основной метрикой, поскольку позволяет учитывать качество классификации каждого класса независимо от его размера.

Дополнительно:
- строится Confusion Matrix;
- анализируются неправильно классифицированные новости;
- сохраняются примеры ошибок для дальнейшего исследования.

### 6. Предсказание на новых данных

Реализуется функция `predict_sentiment()`, которая принимает одну или несколько финансовых новостей и возвращает предсказанную тональность.

Для моделей, поддерживающих `predict_proba`, дополнительно возвращаются вероятности принадлежности к каждому классу.

## Установка и запуск

### 1. Клонирование репозитория

```bash
git clone https://github.com/genaujetzt/financial-sentiment
cd financial-sentiment
```

### 2. Создание виртуального окружения

```bash
python -m venv venv
```

Активация окружения:

**Windows:**
```bash
venv\Scripts\activate
```

**Linux / macOS:**
```bash
source venv/bin/activate
```

### 3. Установка зависимостей

```bash
pip install -r requirements.txt
```

Для использования лемматизации spaCy дополнительно потребуется языковая модель:

```bash
python -m spacy download en_core_web_sm
```

### 4. Подготовка данных

Поместите CSV-файл с финансовыми новостями в директорию `data/`.

Убедитесь, что он содержит колонки `text` и `sentiment`.
